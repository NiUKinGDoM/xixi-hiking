# 版本变更记录 · 存档

> **为什么有这份文件**：`PROJECT_STATUS.md` 是「开工必读」的交接主文档，**只保留当前小版本系列**（现为 v1.2.1.x）
> 的版本详情 —— 历史版本全留主文档里，会让每次接手的开局白吞几万 token 的上下文。更早的记录就放这里。
>
> **维护规则**：① 新版本照旧由 `tools/docrelease.js` 插进 `PROJECT_STATUS.md`；
> ② 当小版本号进位（如 `1.2.1.x` → `1.2.2.x`）时，把上一系列整段搬到本文件顶部；
> ③ 本文件与主工程/仓库**双端同步**（`tools/doc-sync.js`），别只改一边。
>
> **相关**：完整版本时间线见 `CHANGELOG.md`；每条更新的用户可见说明见各 GitHub Release 的 body。
