## 七条最容易犯错的红线

1. **改文件一律走补丁工具**：`node tools/patch.js <补丁.json>`（唯一命中校验 + 写后 `node --check` + 失败自动还原）。`old` 用 **python 切片**提取（自动带正确换行），别手写、锚点要唯一且尽量纯 ASCII；`new` 末行是注释时**必须带换行**。
   **★ 生成补丁的脚本用 `Write` 落一个 `.py` 再 `python xxx.py`** —— 禁 bash 内联 `-c "…"` / heredoc 拼**含转义或反引号**的文本（反引号会被 shell 当命令替换，**文字会被静默掏空**，文件照样写出、不报错）。
2. **样式不要相信 Tailwind**（冻结快照：`px-5`→padding=0、`z-[300]`→auto 都是真 bug）：关键样式内联硬锁或用自定义 CSS；**判定是否生效只能浏览器实测 `getComputedStyle`**，禁凭 grep 下结论。
3. **弹窗 / 按钮只有一套体系**：容器一律 `confirm-modal modal-backdrop-animate`；红色 `.check-go-btn` **只给重要/危险操作**（删除 / 解绑 / 确认执行），**普通选项用中性 `.glass-btn`**，取消用 `.confirm-btn-cancel`。弹窗要显式写 `width: calc(100vw - 44px); box-sizing: border-box`（只写 `max-width` 会随内容跳，守卫 `tools/modalwidth.js`）。禁原生 `confirm/alert`（用 `askConfirm()`）。
4. **禁任何外部 CDN**（离线自足：徒步没信号是常态）：`tools/audit.js` 的 F 段是门禁；新增静态资源要三处同步（`sw.js` CORE_ASSETS + bump `CACHE_NAME`、`tools/security.js` HASH_FILES、`prev-snapshot.js`）。
5. **未确认「同步」前，绝不 bump / 构建 / push**。改完先本地自检 → 需要时按用户明确要求部署网页版预览 → 用户说「同步」才发版。
6. **更新日志必须写全**（用户 2026-09-17 明确定规矩）：按 `【新增/优化/修复/内部】` 分组逐条写「以前怎样 → 现在怎样」，**内部清理与测试项数也要写**。
   **★ 写之前必跑 `node tools/versiondiff.js`**（列出「已发布版 vs 当前工作区」全部改动；`prepare` 会全量打印并留档 `tools/notes/<版本>-diff.txt`），**并把清单逐行过一遍 —— 每一行都要能对应到文案里的某一条**（对不上就补文案、或在【内部】说明为何不用写）。
   ⚠️ 清单要按「**本版将要交付的全部内容**」读，而不是「我这轮改了什么」—— 2026-09-20 真实事故：跨版未发的改动被当成「已报告过」→ 漏写了整条【新增】。
7. **iOS 是网页入口，能力受限**：`navigator.vibrate` 在 iOS Safari **不存在**（守卫静默即可，别当 bug 修）；`a[download]` 保存无效 → 长按引导；原生桥/系统通知需降级。**每次发 APK 同步做 iOS 网页适配**，守护 `tools/ioscheck.js`（已并入 `checkall`）。

## 自检与发版（已全部机制化，别临场写一次性脚本）

- **全套自检**：`node tools/checkall.js` —— **7 套 795 项** = 工具链冒烟 20 + iOS 适配 10 + 数据层/语法 272 + jsdom UI 30 + P0P3 链路 299 + E2E 真实渲染 126 + 弹窗宽度 38
- **浏览器实测**：`node e2e/inspect.js --file <snippet.js> [--dark] [--shot x.png]`
  （snippet 是**函数体**、必须 `return (async () => {…})()`；`new Function(src)` 执行，光写 IIFE 会得到 `undefined`）
- **发版前核对**：`node tools/versiondiff.js` —— 本版改动清单（**必看**，见红线 6）
- **发版**（两段，任一步失败即停）：
  1. `node tools/ship.js prepare --builtin tools/notes/<v>-builtin.txt --doc tools/notes/<v>-doc.txt`
     —— 自动：回退点快照 → bump 版本三处 → bump `CACHE_NAME` → **打印本版改动清单（留档）** → 注入 App 内更新日志 → 同步双端文档 → 全套自检 → 代码审计 → 构建 APK → APK 全面验证
  2. 用户网页版验收 → 用户说「同步」→ `node tools/ship.js publish <tag> tools/notes/<v>-release.md`
     —— 自动：同步副本仓库 + commit + push（触发 CF Pages）→ 建 Release + 上传 APK + 校验
  - **★`prepare` 不幂等**：失败后**绝不能重跑**（会再 bump 一次）。改手动补跑 `checkall.js` → `audit.js` → `release.js` → `verify-apk.js`，再 `publish <原版本> <文案>`。
    且 `builtin.js` / `docrelease.js` 遇「同版本条目已存在」会**静默跳过（exit 0）** —— 改了文案要先移除旧条目再重新注入。
  - **★同号修正重发（政策，用户 2026-09-20 定：「以后像这种的，都同号修正重发」）**：**补正类改动**（文案 / 更新日志 / 文档 / 守卫等**不改用户可见功能行为**）→ **不升号**，原号重新构建覆盖发布。做法：**禁跑 `prepare`**（含 bump）→ 手动 `prev-snapshot.js` → `sw.js` CACHE_NAME+1 → `checkall` → `audit`（先清 `.latest.png`）→ `release.js` → `verify-apk.js` → `ghsync -m "release: vX (rebuild: …)" --push` + `ghrelease.js vX <文案>`（幂等：复用 Release + PATCH body + 删旧 asset 重传）。**代价必先告知用户**：手机同号收不到更新提示 → 需手动下载覆盖安装（Release 说明里也要写）；网页版复核**看内容指纹**（sw CACHE_NAME + 新增文本）而非版本号。**若补正同时改了功能行为 → 先问用户同号还是升号。**
- **版本号**：四段 `1.x.x.x`，每段 0~10 共 11 个值、满 10 进位；`node bump.js` 一键递增（build.gradle + `app-core.js` 的 APP_VERSION + index.html 版本显示）；**汇报版本号一律以 bump.js 实际输出为准**，禁用十进制直觉（`1.1.2.10` 的下一版是 `1.1.3.0`）。**号不可复用**（唯一例外见上条政策）。
- **GitHub / 网络**：一律用现成工具 `tools/ghsync.js` / `tools/ghrelease.js`（hosts 劫持绕行、`--ssl-no-revoke`、钉真实 IP、幂等重跑全都内置）—— **别手拼 token URL、别写一次性脚本**。上传校验以服务端 `digest`(sha256) 为准。
- **★新增守卫/断言必须反向验证**：写完临时撤掉修复跑一次，确认它**真的会报红**；且**锚点必须是「完整句子 / 完整 CSS 规则串」**（`includes(关键词)` 只要该词在别处也出现就是假阳性 —— 2026-09-20 同月踩了 2 次）。

## 环境要点

- bash 的 PATH 会**偶发丢失**（报 Exit 127 / `tail` not found）→ 命令前先：
  `export PATH="/usr/bin:/bin:/c/Windows/System32:/c/Windows:$PATH"`
- 构建必须在 `%TEMP%\hiking-build` 下进行（桌面路径有文件锁）；Release + R8 签名包
- 签名 = `debug.keystore`（SHA-256 `9396fee4…`，备份在 `backups/android-signing/`，**绝不上传**；换密钥须同步改 `SIGN_EXPECT_SHA` 常量）
- node/隔离依赖：`NODE_PATH` 指向 `C:\Users\NIU-XC\.workbuddy\binaries\node\workspace\node_modules`；node 托管路径的版本号会漂移，别写死
- 本机有代理/hosts 劫持（Steam++ 类）→ **本机 curl 结论不代表用户环境**；测网络前先看 `env | grep -i proxy`
- 抓 pages.dev 用脚本时**必须带浏览器 UA**（CF 对 Python `urllib` 默认 UA 返回 403）
