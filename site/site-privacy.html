官网隐私说明

适用范围：本站（xixi-hiking-site.pages.dev）的访问与下载  ·  最近更新：2026-10-13
本页只说明官网；App 自身的数据处理见《隐私政策》，两者相互独立。

一句话概括

官网只是一张介绍页加一个下载入口：不注册、不登录、不使用 Cookie、不做跨站追踪、不接入广告。唯一的统计是「下载按钮被点了多少次」——它只用来知道你大概有多少人下载，而且不保存你的明文 IP，也无法识别出你是谁。

一、官网不做哪些事

不要账号：本站没有任何注册、登录、评论、留言功能，不收集你的姓名、手机号、邮箱或任何身份信息。不使用 Cookie：本站不写入 Cookie，也不使用 localStorage、IndexedDB 记录你的访问痕迹。不做跨站追踪：不接入广告平台、受众画像或再营销工具，不存在把你在本站的行为与其他网站关联起来的做法。不看你浏览了哪几页：本站未启用页面级访问统计，所以我们并不知道你看了哪几页、停留多久、从哪里跳转而来。

二、唯一的统计：下载计数

为了知道「大概多少人真的下载了」，每当有人点击任一「下载」按钮，我们会记录 1 条计数，内容仅包括以下三类：① 时间（服务器自动记录）；② 一个不可逆的去重标识——把你的 IP 与浏览器标识拼接上一段固定盐值后做 SHA-256，只取前 12 字节（24 位十六进制）。它唯一的用途是把「同一个人反复点击」合并成一次，让「下载人数」尽量接近真实人数；③ 下载结果——走了哪条下载通道（镜像或官方直链）、下载的是哪个版本、点的是官网哪个位置的按钮（导航栏 / 手机菜单 / 页面底部）。

需要特别说明的是：我们不保存你的明文 IP 地址（上述标识无法反推出 IP），不记录你的浏览历史，不记录你下载到的文件内容，也不会把这些计数与你的任何账号、邮箱或身份信息建立关联。

三、这项统计存在哪里、会不会出境

计数存储在 Cloudflare 的分析服务上，由 Cloudflare 负责托管——我们没有自己的服务器，这些计数也不经过任何第三方中转、不落入开发者自建的任何数据库。Cloudflare 的节点遍布全球（含中国境外），所以这项计数可能构成个人信息的跨境传输。我们只用它做「计数与去重」这一件事：不用于识别个人、不用于广告投放、不做用户画像，也不与任何其他数据源合并。保留期限遵循 Cloudflare 对分析数据的保留策略，我们不做额外的长期归档。

四、如果你不想被统计

由于这项统计不依赖 Cookie，所以不存在「关闭 Cookie 即退出」的开关。如果你不希望贡献这项计数，可以：① 使用浏览器的无痕 / 隐私模式访问（不产生持久标识）；② 使用广告拦截类浏览器扩展拦截统计请求；③ 直接前往 GitHub Releases 页面下载安装包。以上任一做法都不会影响你下载、安装与使用 App 的任何功能。

五、官网上的第三方请求

① 网页字体：为了让排版好看，本站会向 Google Fonts 请求网页字体，这意味着你的浏览器会向 Google 发出一次请求（Google 会看到你的 IP 与浏览器标识）。如希望完全避免，可用扩展拦截 Google 域名——页面会退回系统字体，不影响阅读。② 下载文件托管：APK 安装包托管在 GitHub Releases（服务器位于中国境外），下载时 GitHub 会记录常规网络请求信息（IP、浏览器标识），该请求同样属于跨境传输，其处理行为适用 GitHub 的服务条款与隐私政策。③ 没有其他第三方脚本：本站未接入广告、统计、客服、热力图等任何第三方脚本。

六、与 App 的关系

本页仅适用于官网。App 自身（Android 客户端与网页版）是纯本地工具：记录、计划、备注、照片全部保存在你的设备上，不设账号、不接入统计或广告 SDK，其数据处理规则请见《隐私政策》；使用与免责条款见《免责声明》。两页与本页相互独立：官网的下载计数不会与 App 内的任何数据发生关联。

七、你的权利与联系方式

由于去重标识不可逆、且不与任何身份信息关联，我们无法定位到具体某个人，因此无法按人查询或删除单条计数——这正是「不识别个人」这一设计的结果。如果你希望整体停止这项统计，可通过下方邮箱告知我们，我们会删除统计数据集并停止记录。任何疑问、意见或投诉，欢迎通过 Xixihiking@foxmail.com 或 GitHub Issues 联系我们，我们将在合理期限内（一般不超过 15 个工作日）答复。本页的订立、效力与解释均适用中华人民共和国法律。
