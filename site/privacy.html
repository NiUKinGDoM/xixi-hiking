隐私政策

适用版本：Android 客户端与网页版 · 生效日期：2026-09-18 · 最近更新：2026-09-18
本页与 App 内「关于应用 → 隐私政策」展示的内容一致。

适用范围与生效

本政策适用于「XiXiの徒步小记」Android 客户端与网页版（以下统称本应用）。生效日期：2026-09-18；最近更新：2026-09-18。本政策随版本迭代更新，重大变更会在应用内提示。

一、数据存储位置与期限

本应用是纯本地工具：记录、计划、备注、照片全部保存在你的设备上（网页版为浏览器本地存储），本应用不设账号体系，不收集、不上传你的个人身份信息、行为数据、设备标识与位置信息，也未接入任何统计、广告或推送 SDK。存储期限由你决定 —— 卸载应用或使用「抹掉所有足迹」即可清除本机全部数据。

二、云备份（可选）

仅当你主动在设置中配置 WebDAV 后，数据才会同步到你本人的网盘账号。服务器地址、账号与应用密码仅保存于本机，采用加密存储，任何界面均不明文展示；与网盘的通信全程 HTTPS，且在你的设备与网盘服务商之间直接进行 —— 本应用没有开发者服务器，数据不经过任何中转。备份文件中可包含一份加密后的网盘配置（便于换机一键恢复），请妥善保管备份文件，避免提供或发送给他人。

三、信息共享、转让与公开披露

本应用不会向任何第三方出售、出租、共享、转让或公开披露你的数据，也不存在与「合作方共享数据」的情形。开发者不持有你的数据，因此任何第三方（含广告商、数据服务商）均无法通过本应用获取你的记录与照片。

四、联网行为与第三方服务

① 检查更新：请求 GitHub Releases 接口查询最新版本号，仅产生常规网络请求信息（IP、User-Agent），由 GitHub 依其自身隐私政策处理；② 云备份：依赖你自行选择的 WebDAV 服务商（如坚果云），其数据处理行为适用该服务商的条款与政策；③ 崩溃报告：仅在已配置网盘的前提下，应用异常时上传一份不含记录与照片的诊断信息（版本号、错误内容、时间），用于定位问题。

五、数据安全措施

本应用采用以下措施保护你的数据：本地数据随应用沙箱隔离；网盘凭据加密存储；Android 包经过签名校验，防止被篡改或替换安装；不申请通讯录、短信、通话记录、精确位置等与功能无关的权限。同时请理解：任何存储方式都无法保证绝对安全，请定期导出备份并自行妥善保存。

六、你的权利

查阅与更正：全部数据在应用内可见、可改；导出与迁移：随时「导出完整备份」带走记录与照片；删除：单条删除、批量删除、抹掉所有足迹（云端旧备份需你自行在网盘删除）；撤回同意：关闭自动同步、解绑网盘账号或卸载应用。上述权利均无需向开发者申请，你在应用内即可直接行使。

七、未成年人保护

本应用不面向 14 周岁以下儿童单独提供服务。未成年人应在监护人指导下使用；户外活动请务必由成年人陪同，并由监护人承担相应监护责任。

八、权限清单与用途

通知：计划与备份提醒；精确闹钟：计划当天早上提醒；开机启动：重启手机后恢复你的计划闹钟；震动：点按反馈；安装应用：协助安装已下载的新版本；存储写入（仅旧版安卓）：把备份写入「下载」目录；照片选择：为记录添加照片。以上权限均可拒绝，拒绝仅导致对应功能不可用，不影响其余功能。

九、政策更新

本政策随功能迭代更新，最新内容始终在本页展示。若更新涉及你的权利或数据处理方式的重大变化，本应用会在应用内以提示方式告知。

十、适用法律与联系方式

如对本政策有疑问、意见或投诉，可通过「关于应用 → GitHub」提交 Issue（问题反馈），或经应用内反馈渠道联系开发者，我们将在合理期限内答复。本政策的订立、效力、解释与争议解决均适用中华人民共和国法律。
