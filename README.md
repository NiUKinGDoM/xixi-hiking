## ✨ 功能一览

| 板⁠块 | 能力 |
|---|---|
| 概⁠览 | 📊 统计主卡（次数/里程/用时/最高海拔）+ 年资 + 年度足迹热力图 + 年度回顾（含"和去年比"） |
| 记⁠录 | 📝 增删改、难度 1-5、小日记、心情/天气、照片（最多 24 张/条）、按年份分组、列表/山册双视图、点行弹窗阅读与编辑 |
| 照⁠片 | 📷 本地压缩存储（IndexedDB）、详情横滑照片墙、全屏灯箱缩放/保存 |
| 计⁠划 | 📅 列表/日历双视图、三态徽章（过期/今天/明天）、**到期计划「完成 / 延期」**、完成自动转记录+庆祝、每天 08:00 通知提醒 |
| 搜⁠索 | 🔍 山名 + 小日记 + 心情/天气/同行人全文搜索，计划日历定位 |
| 分⁠享 | 🖼️ 一键生成分享卡（海拔/难度/心情/天气/同行人） |
| 设⁠置 | ⚙️ 完整备份 zip（**可选带上网盘配置，换机从云端恢复即一键配好**）/ 纯数据备份 / WebDAV 云同步（**网盘信息查看 · 同步状态四维 · 自动保留 2 份**）/ 导出诊断 / 检查更新（内置离线更新日志）/ 深色模式 / 震动开关 / 照片占用优化 / 抹掉足迹 |
| 安⁠全 | 🛡️ 安装包签名自校验（防重打包）+ 打包代码混淆 + 资源完整性校验 + 系统备份关闭 + 服务端文本进 DOM 前一律转义 |
| 适⁠配 | 📐 手机 / 小折叠 / 大折叠 / 阔折叠展开 / 平板 / 网页 —— 展开成大屏时内容自动居中撑满，不浪费一寸屏幕 |

### 📐 屏幕适配说明

| 设备形态 | 布局 |
|---|---|
| 手机 · 小折叠展开（Flip 类） | 单列全宽，与手机一致 |
| 小折叠**合上后的外屏**（极窄屏 ≤350px） | 底部按钮收窄、概览矮卡改竖列、山册统计格排成 3 列 2 行 —— 文字不挤不漏；**宽于 350px 的普通手机完全不受影响** |
| **大折叠 / 阔折叠展开**（Fold、Mate X 系等） | 内容**居中撑满**，充分利用大屏（不会出现右侧大片空白） |
| 平板 / iPad | 内容限宽 900px 居中，长文阅读不累眼 |
| 网页版（桌面浏览器） | 与平板同策略，限宽居中 |

> 折叠屏展开 / 合上会自动重排，无需重启 App。

## 🔒 隐私承诺

- 记录与照片**只存本机**（网页版存浏览器本地），无账号、无统计、无广告
- 联网只有三件事：① 你主动配置的 **坚果云 WebDAV** —— 数据同步到**你自己的**账号（服务器在中国境内）；② 启动时向 **GitHub** 查询新版本号 —— 仅传 IP 与浏览器标识，**不含记录与照片**；**GitHub 服务器在中国境外**，该请求可能构成个人信息的跨境传输，不想发生可离线使用（离线不影响记录与查看）；③ **崩溃报告** —— 仅在已配置网盘的前提下，异常时上传不含记录与照片的诊断信息（版本号、错误内容、时间），用于定位问题
- 完整说明见 App 内「设置 → 关于应用 → 隐私政策」；同一份文本也在官网 <https://xixi-hiking-site.pages.dev/privacy.html>
