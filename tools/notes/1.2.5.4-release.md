## v1.2.5.4 —— 远程配置全面接入（不升号也能调）+ 省电模式

### 新增

- **省电模式**（设置 → 省电模式）
  - 打开后暂停：3 个背景渐变光斑的无限动画、`will-change` 常驻、页面切换的整页转场。
  - **刻意不动** `backdrop-filter` / 圆角 / 字号 / 布局 —— 玻璃质感是既定设计语言，而且静态模糊几乎不耗电，贵的从来是「一直在动」。
  - 实测（393×852）：运行中动画 **27 → 19**，`will-change` 元素 **10 → 7**。
  - 优先级：手动偏好 > 远程 `powerSaveDefault` > 默认关；手动切过就再也不会被远程覆盖。

- **远程公告**
  - 概览页顶部一张玻璃卡：`{ id, text, url, urlText }`。
  - **换 id 才会再次出现**；用户点 ✕ 后同 id 永久不再显示。`id` 留空 = 完全不打扰（默认就是这个状态）。
  - 文本走 `textContent`（实测 `<b>` 不会被解析），url 只接受 `http(s)` ⇒ 远程内容无法注入标签。

- **诊断卡**
  - `debugInfo: true` 时，设置页顶部出现只读卡：版本 / 记录数 / 计划数 / 本地存储占用 / 错误日志条数。
  - 排障时远程打开、让用户截图即可，不必专门装 Debug 包。默认关。

### 优化

- **iOS 网页版自动隐藏用不了的功能**（设置页）
  - **「震动反馈」**：iOS 上所有浏览器（含 Chrome/Edge）都是 WebKit 内核，从来不实现 `navigator.vibrate`。
  - **「检查更新」**：iOS 装不了 APK。
  - 判定用能力检测优先（`typeof navigator.vibrate`），叠加 `isIOS` —— 因为**桌面 Chromium 是有该接口的**，只靠能力检测会在测试环境误判。
  - 只改 `display`，元素仍在 DOM 里（测试断言与将来回退都不必改结构）；隐藏后相邻项间距实测 **10px，与桌面版对应位置完全一致，不留空档**。
  - 逐个核对过 15 个原生桥方法，确认其余都有降级路径（WebDAV → fetch+BasicAuth、存相册 → 浏览器下载、计划闹钟 → 静默跳过），**不做多余隐藏**。

- **A 类参数改为在线可调**（`functions/config.js`）
  | key | 含义 | 默认 | 夹紧范围 |
  |---|---|---|---|
  | `photoMaxSide` | 照片压缩长边 | 1280 | 480 ~ 3000 |
  | `photoQuality` | JPEG 质量 | 0.7 | 0.5 ~ 0.95 |
  | `pageSize` | 列表每页条数 | 10 | 5 ~ 50 |
  | `syncMaxFiles` | 同步索引保留 | 20 | 5 ~ 100 |
  | `davTimeoutRead/Write` | 网盘超时 | 15s / 60s | 3s ~ 180s |
  | `fpsDefault` / `powerSaveDefault` / `hapticDefault` | 各开关默认值 | false / false / true | — |
- **C 类文案可在线覆盖**：`welcome.title` / `welcome.sub` / `welcome.where` / `empty.records` / `empty.plans`。**没配就一个字节都不改**，撤掉配置能还原（原文存 `data-rc-orig`）。
- **类型安全**：`RemoteConfig.num/bool/text` 一律带默认值与夹紧 —— 配置是公开文件，按不可信输入处理；越界自动夹紧、类型写错自动回退，实测 `pageSize:999→50`、`quality:5→0.95`、`syncMaxFiles:"abc"→20`。

### 说明

- 以上「在线可调」**从这一版开始才真正可用**：远程配置的读取代码必须先在包里（feature flag 思路）。之后改 `functions/config.js` → push → 约 1 分钟生效 → App 下次启动拉到。
- 新增状态统一进 `AppState`（`powerSave` / `noticeId` / `debugInfo`），老变量保持原样。
