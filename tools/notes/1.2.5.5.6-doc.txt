### v1.2.5.5.6 —— 修「更新弹窗里出现表格和工程说明」

> 用户：「为什么在发现新版本弹窗里，还是有很多工程类说明，还有表格？？？」

- 【根因】**更新弹窗渲染的是 GitHub Release 的 body**（`app-sync.js:332` 的 `d.body`），而那份 `-release.md` 是给 Release 页面写的技术文档 —— 含验证结果表格、门禁项数、构建细节。所以上一版承诺「只写看得见的变化」时，我只改了 BUILTIN，**弹窗压根没读 BUILTIN**。
- 【修法】
  1. `showUpdateModal` 改为**优先取 App 内置 `BUILTIN_CHANGELOG['v' + tag]`**（手机端文案，只写用户可感知变化）；只有内置没有该版本（如推送了未来版本）才回退 GitHub body。
  2. 兜底：回退时**滤掉 markdown 表格行**（`^\|.*\|$`）并压缩多余空行。
- 【验证】① 有内置条目：弹窗无 `|`、无"门禁"等工程词、显示内置文案 ✅；② 无内置条目：表格被滤掉、正文完整保留 ✅。
- 【纪律】**`-release.md` 从此也不许写表格** —— 虽然弹窗默认不读它，但它是回退路径，且官网 Release 页同样面向用户。
- 【教训】上一版「修文案」只改了 BUILTIN 就以为完事，**没验证数据实际流向**（弹窗读的是哪个字段）。改"显示什么"之前必须先确认"这个位置的数据从哪来"。
