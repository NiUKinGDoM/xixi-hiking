## v1.2.1.8 更新内容

【新增】
- 「网盘信息」按钮：绑定后，解绑旁多了个一样大的「网盘信息」小按钮，点开能看当前网盘的类型、服务器地址、账号；应用密码加密脱敏显示（只显示 ••••••••，绝不明文）
- 同步状态升级成两行四维：网盘数据 + 图片 / 徒步计划 + 徒步记录，一眼看清哪些数据同步了——绿色 ✓ = 已同步、绿色 ○ = 正常（无数据或未超时）、红色 ✗ = 超时未同步或同步失败

【优化】
- 删掉「立即同步」按钮：它和上方「上传」重复了，避免按钮堆太多
- 云端上传 / 下载恢复都带上网盘配置（含加密后的密码）：换手机、重装后从云端下载备份，账号密码一键配好，不用再手动填一遍
- 导入本地备份同样会带上网盘配置，恢复时按你的选择一键配好

【内部】
- 数据管理说明、隐私政策同步更新（密码加密存储、备份文件里含加密配置的说明）
