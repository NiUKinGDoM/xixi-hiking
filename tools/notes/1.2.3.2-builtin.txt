【修复】
- **应用内更新不再「一直下载失败」了** —— 之前点「立即更新」后进度卡住不动、最后报失败，是因为下载通道只有一条，一旦这条通道慢或被挡住就没有退路。现在改成**多条通道自动依次尝试**，任意一条成功就能顺利下完；全部通道都不行才会提示失败，而且提示里会明确告诉你可以换个网络（比如切到 Wi-Fi）再试

【优化】
- **下载安装包更快更稳了** —— 点「立即更新」「下载安装包」时，会先自动挑一条**速度最快的通道**，不再一头撞上容易卡住的那条；万一首选通道不通，会自动换下一条，直到下载完成
- **「关于应用」里的 GitHub 与官方网站入口位置调整** —— 两个入口整行下移到**底部「Made by XiXi」的正上方**，不再夹在简介和按钮中间，找起来更顺手
- **两个入口的图标大小统一了** —— 之前 GitHub 图标看着比官网图标大一号，现在调成一样大，一行横排更整齐
