## v1.2.1.9 更新内容

【修复】
- 同步状态的四维展示位置放错了：上一版把它直接替换掉了设置页上那一行。现已恢复那一行原样（点它还照样弹「同步状态」小弹窗），四维加进这个弹窗里
- 「照片占用」弹窗的宽度也锁定住：以前只设了最大宽度，宽度会跟着里面的内容变（「统计中…」→ 列表 → 排行，长度一变宽度就跳），现已固定

【优化】
- 「同步状态」弹窗内新增两行四维，一眼看清各部分有没有同步：
  - 第一行：网盘数据 / 图片
  - 第二行：徒步计划 / 徒步记录
  - 绿色 ✓ = 已同步、绿色 ○ = 正常（这部分没数据或还没超时）、红色 ✗ = 超时未同步（开自动同步 3 天 / 没开 7 天）或同步失败

【内部】
- 新增 `tools/modalwidth.js`：把「弹窗宽度必须锁定」这个已踩两次的坑固化成体检项（扫出 `#puModal` 这处漏网），并纳入 `checkall` 自检链
- `checkall` 的 `--fast` / `--no-e2e` 由下标切片改为按 key 过滤，避免新增套件悄悄挤掉 P0P3
