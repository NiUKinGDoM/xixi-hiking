## v1.2.5.4（修正重发）—— 省电模式 + 远程配置 + 文案改说人话

### 省电模式（设置 → 省电模式）

关掉四类「一直在动 / 每帧重算」的负担：背景光斑无限动画、全站毛玻璃模糊、页面切换转场、卡片入场动画。

实测：动画 **27 → 19**、`will-change` **10 → 7**、模糊元素 **24 → 0**。

**关掉模糊的代价与补偿**（本次修正的重点）：

| 项目 | 处理 | 原因 |
|---|---|---|
| 弹窗 | 改接近不透明的实底（浅 `#F7F9FC` / 深 `#162032`） | **没有模糊还半透，背后文字会整片浮上来**（截图实证） |
| 底栏 | 补实（浅 0.86 / 深 0.90） | 漂浮在内容上、不在遮罩下，只能靠不透明度撑住 |
| 页面卡片 | **一律不动** | `--glass-alpha` 是浅/深共用的白色系变量，改它会让深色卡片发白、时光机内容看不清 |
| 深色模糊残留 | 补 `body.dark-mode.power-save *` 变体 | 深色玻璃规则 specificity 0,2,1，只写 `body.power-save *` 压不过（实测残留 7 处） |

### 新增：主题 × 省电 矩阵检查（`tools/themecheck.js`，13 项，已进门禁）

针对「926 项全绿却漏掉深色/弹窗视觉问题」补的盲区 —— 原 E2E 只在**默认状态（浅色 + 省电关）**截图，省电模式零覆盖。现在四组合全测，断言：

- 省电开 → 模糊元素必须为 0（浅、深各一条）
- 省电开关**不得改变**卡片/设置项底色
- 省电开 → 弹窗 alpha ≥ 0.95（防穿透）
- 省电关 → 弹窗仍是原值 0.15 / 0.32
- 省电开 → 弹窗内文字对比度（浅 ≥4.0 / 深 ≥3.0）
